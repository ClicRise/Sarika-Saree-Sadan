## Publish on GitHub Pages

This project includes a GitHub Actions workflow that builds the site as static
HTML and deploys it to GitHub Pages whenever you push to `main`.

1. Create a GitHub repository and upload or push these project files to its
   `main` branch.
2. In the repository, open **Settings → Pages** and set **Build and deployment**
   to **GitHub Actions**.
3. Open the **Actions** tab and wait for **Deploy to GitHub Pages** to finish.
   GitHub will show the published site URL in the workflow's deployment job.

The build detects GitHub Pages' base path automatically, so both project sites
(`username.github.io/repository`) and user or custom-domain sites work.
The workflow currently deploys pushes to `main`; change that branch in
`.github/workflows/deploy-pages.yml` if your repository uses another default
branch.
